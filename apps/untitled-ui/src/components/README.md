# Untitled UI components

The files in this directory (plus `src/hooks`, `src/utils` and `src/styles`)
are Untitled UI React open-source components, copied from a project
generated with the official CLI (`npx untitledui@latest init --vite`).
The component sources are unmodified. The stylesheets are reformatted with
the repo's Prettier settings, and `globals.css` drops the typography plugin
and chart rules, which these forms don't use.

Untitled UI React open-source components are MIT licensed.
Source: https://github.com/untitleduico/react
