# Untitled UI components

The files in this directory (plus `src/hooks`, `src/utils` and `src/styles`)
are Untitled UI React open-source components, copied unmodified from a
project generated with the official CLI (`npx untitledui@latest init --vite`).
`globals.css` omits the typography plugin, which only styles `.prose` content.

Untitled UI React open-source components are MIT licensed.
Source: https://github.com/untitleduico/react
